# 笔记软件当记忆

不装专门的记忆库，把记忆写在您自己的笔记里，让 AI 按您定的规则去读、去记。

- **适合**：已经在用 Obsidian、Logseq、Notion 这类笔记软件；希望记忆完全归自己、换模型也带得走；愿意自己定规则、偶尔整理。
- **不适合**：希望装好就不用管。这种做法没有自动提取、去重和遗忘，记得好不好全看 AI 守不守规则。想省心，请选推荐结果里的记忆库。

和官方 App 自带的记忆相比，好处是：记忆是您自己的文件，能分类、批量改、留历史；Claude、Codex、Gemini 或本地模型都能读同一份。

## 一、本地笔记库（Obsidian、Logseq 等）

Obsidian 的笔记库本质上就是电脑上的一个文件夹，里面是普通的 Markdown 文件。Logseq 也一样。

### 1. 建一个记忆文件夹

在笔记库里建一个文件夹，比如：

```
记忆/
  关于我.md        称呼、作息、喜好、正在做的事
  约定.md          您希望 AI 一直遵守的事
  日记/
    2026-10-28.md  每次聊完追加几条要点
```

### 2. 让 AI 能读写这个文件夹

任选一种：

- **能读写文件的 Agent**（Claude Code、Codex、Gemini CLI、OpenCode、Cursor）：直接在笔记库文件夹里打开它，不用装别的。
- **Claude 桌面版**：装官方的 Filesystem MCP，只允许它访问笔记库。在 Claude 桌面版的「设置 → 开发者 → 编辑配置」里加上（路径换成您的笔记库）：

  ```json
  {
    "mcpServers": {
      "notes": {
        "command": "npx",
        "args": ["-y", "@modelcontextprotocol/server-filesystem", "D:/笔记库"]
      }
    }
  }
  ```

  需要先装 Node.js。
- **笔记软件连接器**：想让 AI 用上笔记软件自己的搜索、标签、双链，或者想局部修改某一段，可以装推荐结果里列出的连接器（Obsidian、Logseq、Anytype 都有）。其中不少要求笔记软件一直开着。

### 3. 写一段读写规则

把下面这段放进 Agent 的说明文件（Claude Code 是笔记库根目录的 `CLAUDE.md`，Codex、OpenCode 是 `AGENTS.md`，Gemini CLI 是 `GEMINI.md`）；Claude 桌面版可以放进项目的「指令」里。按自己的习惯改：

```markdown
## 记忆

- 每次对话开始，先读 `记忆/关于我.md` 和 `记忆/约定.md`，再读 `记忆/日记/` 里最近 3 天的文件。
- 我说“记住……”时，写进对应的文件；不确定写哪里时先问我。
- 对话结束前，在 `记忆/日记/今天的日期.md` 末尾追加 3～5 条要点：发生了什么、做了什么决定、我的心情。
- 发现记忆和我现在说的矛盾时，先问我，确认后再改，并在旁边注明修改日期。
- 不要删除任何记忆文件；过时的内容移到 `记忆/归档/`。
- 密码、证件号、银行卡这类信息不要记。
```

### 手机怎么办

手机上的官方 App 读不到您电脑上的文件。可以：

- 用同步工具把笔记库同步到手机（Obsidian Sync 要付费；也可以用 iCloud、Git），在手机上看和改；AI 读写仍在电脑上进行。
- 用 Claude App 的 Remote Control、ChatGPT App 的 Remote 遥控电脑上的 Claude Code 或 Codex。
- 把连接器放在服务器上、做成远程连接（推荐结果里标了“可远程”的那个），门槛较高。

## 二、Notion

Notion 有官方托管的远程连接器，不用在电脑上装任何东西，免费版也能用。

1. 在 Notion 里建一个「记忆」页面，下面分「关于我」「约定」「日记」几个子页面，或建一个数据库。
2. 在 AI 客户端里添加远程 MCP，网址填 `https://mcp.notion.com/mcp`，按提示登录 Notion 并授权：
   - Claude Code：`claude mcp add --transport http notion https://mcp.notion.com/mcp`，再在 `/mcp` 里登录。
   - Claude 网页版：在「设置 → 连接器」里添加自定义连接器（要付费套餐）；添加后 Claude 桌面版和手机 App 也能用。
   - ChatGPT：自定义连接器目前只能在网页端添加和使用。
   - 其它客户端见 [Notion 的说明](https://developers.notion.com/docs/get-started-with-mcp)。
3. 把上面的读写规则改成“读 Notion 里的「记忆」页面”，放进客户端的指令或项目说明里。

注意：记忆存在 Notion 的服务器上，经过 Notion。

## 和记忆库相比缺什么

| | 笔记软件当记忆 | 专门的记忆库 |
|---|---|---|
| 记什么、什么时候记 | 全看规则和 AI 是否照做 | 自动提取 |
| 重复、矛盾 | 要自己定期整理 | 多数会去重、更新 |
| 遗忘 | 没有，文件越来越多 | 部分有衰减或归档 |
| 查找 | 读文件或全文搜索 | 多数有语义检索、排序 |
| 查看和修改 | 最方便，就是普通笔记 | 看项目，有的要面板或命令 |
| 换模型、换客户端 | 最容易 | 看项目 |

两者也可以一起用：记忆库负责自动记，笔记里放您亲手写的、最重要的内容。
