### 2.6 首页叠加的 UI 元素

沙漏是首页的主体，以下 UI 元素叠加在 Canvas 上方，用 HTML/CSS 定位，**不在 Canvas 里绘制**。

#### 主入口："find yours →"

在沙漏下方、底部沙堆再往下的位置，一行文字：

```
find yours →
```

- 字体：Cormorant Garamond，与沙漏文字相同的衬线体，字号约 18px–20px，颜色 #111。
- **样式上像是沙漏里沉到最底部的最终结论**，是叙事的自然延伸，不是一个按钮。
- 鼠标悬停时：文字向右轻微位移 4px，透明度从 1 变为 0.7，transition 0.3s。
- 点击后跳转到问卷页。

## 三、字体方案

### 3.1 英文：Cormorant Garamond

- 来源：Google Fonts，免费开源（OFL-1.1 许可证）。
- 用途：沙漏动效中的所有英文单词、首页"find yours →"、问卷页中可能出现的英文。
- 字重：沙漏中的单词随机使用 300–600 之间的字重，增加颗粒感层次。首页入口文字用 400。
- 加载：通过 Google Fonts 的 `<link>` 标签加载，只加载 300, 400, 500, 600 四个字重。

### 3.2 中文：思源宋体（Source Han Serif SC / Noto Serif CJK SC）

- 用途：首页标语、"浏览全部"、问卷页所有中文内容。
- **首页**：因为只有十几个汉字，使用 **font-subset（字体子集化）**，只打包首页实际用到的汉字，压到几十 KB。用 `pyftsubset`（fonttools 的命令行工具）或类似工具生成子集 woff2 文件，自托管在项目中。
- **问卷/详情页**：在 CSS 中写 fallback 链：
  ```css
  font-family: "Source Han Serif SC", "Noto Serif CJK SC", "STSongti-SC-Regular", "STSong", "SimSun", serif;
  ```
  有思源宋体的设备用思源宋体，没有的回退到系统宋体。后续正式部署时可以考虑加载完整字体。
- 字重：标题用 600，正文用 400。

### 3.3 CSS 变量

把字体统一定义为 CSS 变量，方便全局调整：

```css
:root {
  --font-en: 'Cormorant Garamond', 'Georgia', serif;
  --font-zh: 'Source Han Serif SC', 'Noto Serif CJK SC', 'STSong', 'SimSun', serif;
  --color-bg: #F4F3EF;
  --color-text: #111111;
  --color-muted: #999999;
  --color-faint: #aaaaaa;
}
```

## 四、视觉规范

- 背景色：#F4F3EF（米白）。
- 文字颜色：#111（近黑）。
- 沙漏中的单词大小略有随机变化（基础字号 14px–20px 之间随机），落下后保留自然的随机旋转角度。
- 沙漏在屏幕中央，大小按屏幕高度等比缩放。手机竖屏和电脑横屏都适配。窗口尺寸改变时墙体同步调整。
- **全站不使用 emoji、圆角卡片、阴影、渐变色**。视觉语言是：衬线体 + 大量留白 + 物理运动。
- "find yours →" 中的箭头用文本字符 →（U+2192），不用图标库。

---

## 五、性能要求

- 移除的单词要从 Matter.js 物理世界中**彻底删除**（removeBody），长时间运行不能变卡或内存泄漏。
- 静止的单词让物理引擎休眠（Matter.Sleeping）。
- 手机上也要保持流畅。如果检测到设备性能较弱（如 `navigator.hardwareConcurrency <= 4`），减少同时存在的单词数量上限。
- 首页加载优先级：先渲染背景和 UI 文字，再加载 Matter.js 和启动动效。Canvas 动效不阻塞首屏渲染。
- 如果用户系统开启了"减少动态效果"（`prefers-reduced-motion: reduce`），直接显示堆积好的静态结果，不运行物理引擎。

## 六、可调参数

把以下参数（供参考）集中写在文件开头的一个 `CONFIG` 对象里，方便我自己修改：

```javascript
const CONFIG = {
  // 数据
  sentencesUrl: './hourglass-sentences.json',

  // 时间（毫秒）
  sentenceDisplayDuration: 1500,   // 新句子停留时间
  wordReleaseInterval: 150,        // 单词逐个松开的间隔
  filterInterval: 3000,            // 瓶颈放行间隔
  fadeOutDuration: 800,            // 不通过的词消失时间
  bottomFadeOutDuration: 3000,     // 底部最旧的词淡出时间

  // 数量
  topMinWords: 40,                 // 上半部分最低词数，低于此补充新句子
  bottomMaxWords: 12,              // 下半部分最多词数
  bottomInitialWords: 6,           // 页面打开时下半部分预置词数

  // 视觉
  fontFamily: "'Cormorant Garamond', Georgia, serif",
  fontSizeMin: 14,
  fontSizeMax: 20,
  fontWeights: [300, 400, 500, 600],
  bgColor: '#F4F3EF',
  textColor: '#111111',

  // 物理
  gravity: 0.6,
  restitution: 0.2,                // 弹性（0 = 不弹，1 = 完全弹）
  friction: 0.3,

  // 沙漏形状（占屏幕高度的比例）
  hourglassHeight: 0.75,
  neckWidth: 0.04,                 // 瓶颈宽度（占沙漏宽度的比例）
};
```

## 七、问卷页设计方向

问卷页在首页确认后再做，但请**预留跳转结构**。以下是设计方向，供参考：

### 7.1 整体风格

- 延续首页的视觉语言：Cormorant Garamond + 思源宋体、米白背景、近黑文字、大量留白。
- **不引入首页没有出现过的视觉元素**：不用卡片、阴影、圆角矩形、彩色标签、进度条。
- 一些skills和设计原则供你参考：nutlope/hallmark、apple design、wrtie-swift、pick-ui-library；避免不必要的次要标签、说明文字、辅助文案、描述性文字和冗余的微文案。 让布局、视觉层级、间距和清晰的主操作自己完成解释。 具体要求： - 优先用强视觉层级和自解释的结构，而不是用文字去解释。 - 默认不要添加 slogan 式文字、教学段落，或在每个区块下都加“帮助说明”。 - 如果确实需要补充信息，优先使用 info 图标 + tooltip，而不是始终显示的次要文字。 - 保留必要的表单标签和可访问名称（方便读屏软件）。界面清爽不能牺牲可访问性。 - 危险或不可逆操作（删除、支付、提交永久性变更）必须保留清晰的后果提示。 - 去掉说明文字后，第一次使用的人仍应能看懂：下一步点哪里、点了会发生什么。 重写已有界面时：先去掉冗余标签和说明，如果清晰度下降，再优化布局和按钮文案。

### 7.2 一题一屏

- 每屏只展示一道题。题目文字居中偏上，选项纵向排列在下方。
- 选项就是一行行文字，不用矩形包裹。点击时有轻微的颜色或字重变化（例如从 400 变为 600）。
- 选完一题后，当前题目向上淡出，下一题从下方淡入。延续沙漏"向下"的方向感。
- 支持返回上一题（左上角一个 ← 箭头，文本字符，不用图标）。

### 7.3 进度指示

不用进度条。在右上角用一个小数字：`3 / 8`（第 3 题，共 8 题）。字号 13px，颜色 #aaa。

### 7.4 结果页

- 推荐的项目从上方一个一个淡入，先出现最匹配的。
- 每个项目用一行标题 + 一两句推荐理由。点击展开详情。
- 被排除的项目折叠在最下方，标题是"被过滤掉的项目"——呼应沙漏里消失的词。
- 提供"复制结果"功能。
