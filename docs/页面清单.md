# 网站页面清单

共 7 个页面，加一套各页共用的公共组件。详情页是一个模板，每个项目生成一页。真正需要逐页设计的是首页、问卷页、结果页、项目目录页、项目详情页这 5 个；推荐项目页和关于页套用公共组件就行。

## 1. 首页

**要完成的事**：让第一次来的人在几秒内明白这个网站能帮他做什么，然后点进问卷。

| 组件 | 说明 |
|---|---|
| 标题和副标题 | 一句话说清网站是做什么的 |
| 三个入口卡片 | 开始问卷（主要入口）、浏览全部项目、推荐一个项目 |
| 三步说明 | 例：回答几个问题 → 看推荐结果 → 按教程装上 |
| 信任说明 | 收录了多少个项目、信息核实到哪天、“未经实际安装验证”的声明 |
| 页脚 | 关于、反馈方式等链接 |

## 2. 问卷页

**要完成的事**：一题一题地问清用户的情况（18 题，加第 3a 题追问），尽量不让人中途放弃。

| 组件 | 说明 |
|---|---|
| 进度条 | 显示第几部分、第几题 |
| 题目卡片 | 题目、帮助小字（解释术语） |
| 单选、多选 | 多选里有“都不想”这类互斥选项，选了它其他选项自动取消 |
| 排序题 | 点选先后顺序，或拖动排序 |
| 默认勾选提示 | 有默认选项的题目说明“已帮您选好，可以改” |
| 上一题、下一题按钮 | 必答题没答时提示 |
| 跳题 | 根据前面的回答显示或跳过某些题（比如第 3a 题只在选了 Agent 时出现） |
| 续答 | 中途离开，下次打开能接着答（答案只存在用户自己的浏览器里） |

## 3. 结果页

**要完成的事**：给出推荐，并说清楚为什么推荐、需要什么、有什么风险；结果为空时告诉用户放宽哪一条能有结果。

| 组件 | 说明 |
|---|---|
| 结果摘要 | 共推荐几个，概括用户的主要条件 |
| 推荐卡片列表 | 名称、一句话简介、3 条推荐理由、上手难度标签、需要的账号和费用、风险提示、“需自行确认”的项、“方便自己改”标记 |
| 补充部件区 | 可以和主推荐搭配的上下文工具、情绪模块 |
| 组合方案卡片 | 设计上搭配使用的两三个项目 |
| 相关教程 | 搭建指南类条目 |
| 放宽建议 | 结果少或为空时显示“放宽哪一条就多几个” |
| 提醒条 | 例：“您用的官方 App 目前接不了记忆库” |
| 被排除的项目 | 默认折叠，展开后看每个项目被排除的原因 |
| 操作按钮 | 复制或导出结果、重新填写 |

## 4. 项目目录页

**要完成的事**：让不想填问卷的人自己浏览、筛选全部项目。

| 组件 | 说明 |
|---|---|
| 搜索框 | 按名称、简介搜索 |
| 筛选栏 | 接入方式、运行位置、上手难度、能配合的入口、费用、类别；手机上收进一个“筛选”按钮 |
| 排序 | 按星数、最近更新、难度 |
| 项目卡片 | 以网格或列表排列，带风险标记、社区推荐标记 |
| 空状态 | 筛选后没有结果时，提示去掉哪个条件 |

## 5. 项目详情页

**要完成的事**：把一个项目的情况讲清楚，让用户判断自己能不能用、值不值得装。

| 组件 | 说明 |
|---|---|
| 标题区 | 名称、一句话简介、类别、星数、最近一次提交、许可证、仓库链接 |
| “能不能用”信息块 | 能接哪些入口、装在哪里、上手难度、账号和费用、手机能不能连上、只用手机能不能装好 |
| 特性清单 | 19 个特性，逐项标“有”或“文档没写” |
| 记忆机制 | 怎么写入、会不会遗忘、按什么排序、怎么处理情绪等，每项一句白话 |
| 风险提示 | 停更、许可证限制等 |
| 搭配项目 | 设计上可以一起用的项目 |
| 来源说明 | 信息来源、核实日期、“未经实际安装验证”的声明 |

## 6. 推荐项目页

**要完成的事**：收集用户推荐的新项目（提交功能需要后台，可以晚一点再做）。

| 组件 | 说明 |
|---|---|
| 表单 | 必填：仓库链接、名称、一句话介绍；选填：能接哪些助手、运行位置、推荐理由、联系方式 |
| 防垃圾字段 | 对用户不可见，用来拦截机器人 |
| 提交状态 | 提交成功、提交失败的提示 |

## 7. 关于页

**要完成的事**：说明网站的来历和规则，建立信任。

| 组件 | 说明 |
|---|---|
| 网站用途 | 为谁做、能解决什么问题 |
| 收录和排除标准 | 什么样的项目会收进来、什么样的会被排除 |
| 信息来源 | 数据从哪里来、多久核实一次 |
| 术语表 | MCP、Agent 等词的白话解释 |
| 反馈方式 | 发现信息有误怎么告诉我们 |

## 公共组件（各页共用，网站的风格主要由它们决定）

- 顶部导航，手机上收成菜单
- 页脚
- 按钮：主要、次要、纯文字三种
- 卡片
- 标签：难度、风险、类别
- 提示条：普通信息、警告
- 术语提示：点一下或鼠标悬停时显示白话解释
- 折叠面板
- 空状态、加载中
- 表单控件：单选、多选、输入框、拖动排序
- 线条图标（不用 emoji）
