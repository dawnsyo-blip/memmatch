- 4.记忆生成：从聊天内容生成记忆

  - 对于需要记忆的内容，你更倾向于让 agent 完全独立判断，还是人工把关？
    自主性与可控性

    - Agent 完全独立判断：速度更快，但记忆未必精准，记忆库冗余速度更快

    - 保留人工把关环节：记忆更精简，记住更重要的事情，但需要在录入时或者定期花费时间与精力审查

  - 对于交给agent进行判断的部分，你更倾向于让主 Agent 完成所有记忆任务，还是由子 agent 把关？
    自主性与可控性

    - 记忆任务：记忆生成、记忆整合（摘要）

    - 完全由主 Agent 实现；无法即时写入记忆库（因为无法异步执行记忆生成，但可以通过dream来实现在空闲时间的记忆录入）；打断对话；上下文更长，时间更长；有更丰富的世界知识、有完整的上下文，有更多资源来判断什么是重要的（不一定代表模型一定能够理解什么是重要的记忆，因为需要结合gateway的设计来判断）；

    - 由子 agent 把关：使用更轻量的模型可以节约token；更轻量的模型没有完整的上下文，未必可以理解什么是重要的记忆

  - 你最多能够接受记忆录入需要多长时间？（李克特1-5量表，1=1分钟，5=5分钟）
    记忆录入的时间与成本的敏感性

    - 说明：录入快=能够接受flash类子agent或异步处理；录入慢=可以使用图结构类记忆，记忆结构更完整

    - 接受程度更高/能够接受子agent 异步处理：更多推荐zep等图结构记忆库

    - 接受程度更低：更多推荐mem0等文档型记忆库，更多推荐录入时延相关benchmark上表现突出的项目

    - 疑问：似乎除了图结构需要很长时间，其他记忆项目所需要的时间并不长？
