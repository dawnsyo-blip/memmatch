# 中文网页排版规范

依据：W3C《中文排版需求》（clreq）的原则；赫蹏（sivan/heti，MIT）的网格数值；《中文文案排版指北》（sparanoid/chinese-copywriting-guidelines，MIT）的文案规则。英文设计 skill 给出的字号、行高多按拉丁字母设定，**用于中文时以本文件为准**。

## 1. 一切从“基准行”出发

中文字是方块字，排版靠网格对齐。先定两个单位，其余全部取它们的倍数：

- **横向单位 = 正文字号**（默认 16px）
- **纵向单位 = 正文行高**（16px × 1.5 = 24px）

间距只用纵向单位的倍数：`0.25 / 0.5 / 1 / 1.5 / 2 / 3` 倍 → 6、12、24、36、48、72px。组件内边距可用 4px 的倍数微调，但区块之间的间距必须落在上面这组数里，否则视觉对不齐。

把这些写成 CSS 变量（`--unit-inline`、`--unit-block`、`--space-*`），全站只引用变量，不写裸数字。

## 2. 字号阶梯与行高

| 用途 | 字号 | 行高（取 24px 的倍数或其一半） |
|---|---|---|
| 页面大标题 h1 | 32px | 48px |
| 区块标题 h2 | 24px | 36px |
| 小标题 h3 | 20px | 36px（或 30px） |
| 卡片标题 h4 | 18px | 24px–27px |
| 正文 | 16px | 24px（1.5）；长段落阅读区可放宽到 1.75 左右 |
| 辅助说明、标签 | 14px | 21–24px |
| 最小字号（注释、角标） | 12px | 18px |

- 手机上正文**不小于 16px**（iOS 小于 16px 的输入框会触发自动放大）。
- 中文行高比英文大：正文 1.5–1.8，标题 1.25–1.5。不要沿用英文常见的 1.2。
- 字号种类控制在 5–6 级以内；同一层级只用一种字号。

## 3. 段落、标题与行宽

- 段落之间空 **1 个纵向单位**（24px），段首**不缩进**（网页习惯）。二者只选其一，不要既空行又缩进。
- 标题上方空白大于下方空白（如上 1.5–2 倍单位、下 0.5 倍），让标题贴近它统领的内容。
- **行宽 30–42 个汉字**（约 `max-width: 42em`）。超过这个宽度要分栏或加大边距；手机上自然满宽，左右留 16px。
- 列表项之间 0.25–0.5 倍单位；列表与前后段落之间 0.5–1 倍单位。

## 4. 字体栈

```css
/* 黑体（默认界面字体） */
font-family: system-ui, -apple-system, "PingFang SC", "Hiragino Sans GB",
  "Microsoft YaHei", "Source Han Sans SC", "Noto Sans CJK SC", sans-serif;
/* 宋体（需要书卷感的标题或长文时） */
font-family: "Songti SC", "Source Han Serif SC", "Noto Serif CJK SC", SimSun, serif;
/* 等宽（命令、代码） */
font-family: ui-monospace, "SFMono-Regular", Menlo, Consolas, monospace;
```

- 西文字体放在中文字体前面，西文字母才会用西文字体显示。
- 中文网页字体文件很大（数 MB），**不要整套引入中文网络字体**；需要特殊标题字时，只对标题做子集化。
- 字重：正文 400，强调 600。中文没有真正的斜体，**不要用 `font-style: italic` 表示强调**，用加粗或着重号。
- 正文字距保持 0；全大写英文、徽标短词可加 0.02–0.05em。

## 5. 中西文混排与标点（文案规则）

1. 中文与英文、数字之间**加一个半角空格**：`用 Claude Code 写代码`、`共 236 个项目`。
2. 数字与单位之间加空格（`10 GB`），但度数、百分比不加（`90%`、`20°`）。
3. 全角标点与相邻字符之间**不加空格**。
4. 中文句子用**全角标点**；数字用半角；完整英文句子、专有名词内部用半角标点。
5. 不重复使用标点（不写“！！”“？？”）。
6. 专有名词大小写正确：GitHub、iPhone、DeepSeek、SillyTavern。
7. 引号沿用本项目已有写法：中文弯引号“”‘’。
8. 用户可能复制的内容（命令、网址、代码）放在等宽字体里，不要被自动换行或标点挤压破坏。

## 6. 换行与对齐

- 正文**左对齐**，不要两端对齐（中西文混排时两端对齐会拉出难看的空隙）。
- `word-break: normal; overflow-wrap: anywhere;` 防止长网址撑破手机布局。
- 标点不出现在行首：设 `line-break: strict;`。
- 数字表格用 `font-variant-numeric: tabular-nums;`，数字列右对齐。

## 7. 本站的界面文案

- 全站少用英文缩写和术语；必须用时括号或悬停提示给出白话解释（如“MCP（让 AI 调用外部工具的通用接口）”）。
- 一句话说清一件事，按钮用动词开头（“开始问卷”“复制结果”）。
- 称呼用户统一用“您”（负责人 2026-10-25 定）。引号里转述的用户原话、示例对话可以保留“你”。
- **不使用 emoji**（负责人 2026-10-25 定）：界面、文案、按钮、标题、提示条里都不用；需要图形提示时用线条图标（SVG）。

## 8. 自查清单（每个页面完成后）

- [ ] 所有间距都来自变量，区块间距是 24px 的倍数
- [ ] 正文 16px、行高 1.5 以上，行宽不超过约 42 个汉字
- [ ] 标题与下文的距离小于与上文的距离
- [ ] 中英文、中文与数字之间有空格；中文用全角标点
- [ ] 没有斜体中文、没有两端对齐的混排段落
- [ ] 称呼用户统一是“您”；没有 emoji
- [ ] 375px 宽度下没有横向滚动，长网址能断行
