# Codex 生成 · 记忆之间

独立的静态网页设计稿，包含问卷首页 `index.html` 与答题页 `quiz.html`。本目录内的文件均为 Codex 新生成材料。原项目文件只读，未作修改。

## 使用

双击 `index.html` 即可使用，不需要安装依赖或启动服务器。整套页面不依赖网络字体、远程图片或接口。也可在本目录执行 `python -m http.server 4173 --bind 127.0.0.1` 后打开本机地址。

## 内容依据

- `../ROADMAP.md`、`../README.md`
- `../记忆库推荐问卷 v6 文字稿.md`
- `../data/questionnaire/questions.json`，版本 v6-2026-10-28
- `../docs/前端/页面清单.md`，题目数量以当前 v6 配置为准
- `../engine/rule-engine.js` 与项目数据，仅复用问卷条件判断及推荐规则

没有读取任何已有 HTML、CSS 或前端布局脚本作为设计依据。设计重新构建，依据本次用户提供的浅色／深色拟态参考图与设计提示词。

## 数据与隔离

运行 `node build-source.mjs`，只读取原项目数据，并将独立快照写入本目录的 `assets/generated-data.js`、`assets/generated-engine.js`。页面不写入原站答卷，使用独立存储键。网站名称“记忆之间”为此次设计稿的暂定名称。

## 交付范围

首页、完整配置驱动答题流程，以及答完后的推荐摘要。项目目录在首页弹窗内提供搜索和仓库入口；关于问卷弹窗说明隐私与推荐依据。没有新增后端或部署服务。

验证记录与开发经验见 `codex.md`。
