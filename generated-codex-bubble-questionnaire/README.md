# Codex 生成 · 记忆之间

独立的浅色静态网页样张，包含问卷首页 `index.html`、答题页 `quiz.html` 和可直接体验拖拽的排序样张 `ranking-sample.html`。本目录内的文件均为 Codex 新生成材料。原项目文件只读，未作修改。

## 使用

双击 `index.html` 即可使用，不需要安装依赖或启动服务器。整套页面不依赖网络字体、远程图片或接口。也可在本目录执行 `python -m http.server 4173 --bind 127.0.0.1` 后打开本机地址。

当前三张 HTML 均为手机优先页面，使用 `assets/mobile.css`。电脑上打开也按最多 440px 宽居中显示；手机上按实际屏幕宽度铺开，包含安全区域适配与底部主操作。

选项为单列，自上而下排列，44px 气泡位于文字左侧。排版沿用项目 `zh-web-typography` 的标题 32px／48px、正文 16px／24px、区块标题 24px／36px、手机左右 16px 留白。字体按用户确认的轻盈方案改为中文思源黑体、英文与数字 Inter：标题 Light 300，正文与按钮 Regular 400。题目标题保持自然字距、左对齐，第一行尽量排满后自然换行。

字体全部放在 `assets/fonts/` 内，中文字体按实际页面与数据文字制作子集，无需访问字体 CDN。许可证与再生成方法见 `assets/fonts/README.md`。

普通选项与排序条目共用气泡尺寸、内边距和列间距，气泡中心与文字左边线统一；标题、进度条和底部操作共用页面边距，右侧图标与主操作箭头对齐。

- `index.html`：首页样张。
- `quiz.html`：气泡选择题样张。
- `ranking-sample.html`：直接体验已选置顶和整行拖拽，无需先完成前面的题目。

## 交互设计

只保留一套雾白与石墨灰的浅色主题。背景 #F3F3F3、正文 #333333、次要文字 #696969、主按钮 #3B3B3B，使用灰阶与柔和光影表达层次。答题选项本身就是圆形气泡：未选为柔和外凸，戳下后内凹；再次戳下可取消多选。排序题被选中的选项移到最上方，整行支持鼠标和触屏拖拽，可戳前方小气泡取消选择；上移、下移放在条目右侧菜单，方向键也可排序。减少动态效果偏好下停用按压动画。

首页 16 颗泡泡也可各自戳下、再次点击恢复。支持鼠标、触屏及空格／回车，方向键可在泡泡之间移动，整组只占一个 Tab 停靠点；没有新增常驻说明文字。

首页去掉口号、步骤说明和重复标签。题目与选项的补充信息通过 info 按钮按需打开，支持触摸、键盘、Escape 关闭和焦点返回。原生表单标签、读屏说明、输入错误、本地保存失败及清空答卷的后果提示保留。

题目说明不再附加“可选择多项”等通用开场白，仅展示该题原有补充内容；没有补充内容时不显示空的 info 按钮。必要操作方式仍保留为读屏说明。

## 数据与隔离

运行 `node build-source.mjs`，只读取原项目数据，并将独立快照写入本目录的 `assets/generated-data.js`、`assets/generated-engine.js`。页面不写入原站答卷，使用独立存储键。网站名称“记忆之间”为此次设计稿的暂定名称。
