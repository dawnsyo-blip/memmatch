# Codex 生成 · 开发记录

## 工作边界

- 仅在 `generated-codex-bubble-questionnaire/` 内创建和编辑文件。
- 不修改现有页面、问卷、数据、项目文档及配置。
- 不参考已有 HTML 的风格、元素、结构或布局；未读取这些文件。
- 阅读了 roadmap、README、v6 文字稿、问卷配置、页面清单与引擎接口。

- 中文排版参考 `.claude/skills/zh-web-typography/SKILL.md`；无 emoji，控件使用内联 SVG。

## 设计方向

依据用户后续明确要求，只保留雾蓝浅色主题。用克制的外凸、内凹和哑光表面建立触觉层级。圆形几何用于品牌、主视觉和选项本身；每个选项以“戳气泡”方式选择，选中后凹陷，点击的 220 毫秒内出现轻微压缩反馈。排序题选中项移到上方，以整个条目支持鼠标、触屏拖动，前方小气泡显示名次并能取消选择。布局与项目现有星空、纸面样式独立。

用户最新要求先看样张，本轮以三张可直接打开的浅色样张为交付边界，不继续扩展功能。`ranking-sample.html` 使用内存示例，不覆盖用户的答题存档。

## 已遇到的问题

- 初次 shell 调用长时间未返回，恢复后才开始读取和生成文件。
- Windows PowerShell 对 Node `-e` 内嵌引号的传递不稳定；较长逻辑写入本目录的 `.mjs` 后执行。
- 页面清单中的题数落后于当前 v6，遵循 `questions.json` 的题号与四部分配置。
- `q7` 是显示第 6 题，`q6` 是显示第 7 题；不得根据配置 id 推断展示顺序。
- 页面以传统脚本加载独立数据快照，避免 `file://` 下 fetch／ES module 的跨源限制。

## 验证

系统 Edge 对当前手机样张执行了 44 项检查，全部通过，未出现未捕获的脚本异常：

- 本地双击 HTML 可加载，无需服务器。
- 单一浅色主题，选择操作发生在圆形气泡上，选中后凹陷，再戳可取消多选。
- 排序选项被选中后离开下方气泡区，进入上方已选列表。
- 鼠标拖动整个条目可以改变顺序，触屏拖动同样有效。
- 条目菜单中的上下移动仍可用，键盘方向键同样可以排序，取消选择后项目返回气泡区。
- 排序样张不会覆盖已保存的答卷，刷新恢复初始示例。
- 1440px 桌面上按手机宽度展示，320px、375px、390px、430px 手机视口无横向溢出，减少动态效果偏好生效。
- 首页主操作在手机一屏内，答题主操作固定在底部。
- info 弹层能按需展开、在视口内展示、通过 Escape 关闭；选项 info 不会误触选择。
- 用浏览器可访问性树确认原生复选框保留准确的名称。
- 清空答卷仍保留“无法恢复”的明确后果提示。

复现命令：`node verify-samples.mjs`。需系统 Edge，测试仅写入本生成目录。检查报告为 `artifacts/qa-samples-report.json`。最终截图为 `home-desktop-light.png`、`quiz-desktop-light.png`、`ranking-desktop-light.png` 及相应的 mobile 版本。临时浏览器配置与截图目录已忽略。

## 后续经验

- 排序气泡被移入上方列表后，要把键盘焦点交给新条目，不能继续定位已经从下方移除的控件。
- 对整行使用 Pointer Events，可以共享鼠标、触屏交互。只在排序行限制触摸滚动，页面其余区域仍能正常上下滚动。
- 在拖动开始时批量读取位置，移动时只改 transform，结束后再更新数据顺序；取消手势时恢复原顺序。
- 原生 dialog 的 close 事件是异步的，自动检查应等待滚动锁释放，不能用固定的极短延时判断。
- 根据用户最新要求及时收敛到样张，正式上线与全面流程验收留待设计确认之后。

## 手机版本与文案收敛

- 三张 HTML 改用独立 `mobile.css`，默认最多 440px 宽，直接在电脑上即可预览手机排版。
- 删除首页口号、英文副标、三步介绍、主视觉标注、页脚说明。首页保留用途标题和主操作。
- 删除重复的分部分导航、常驻教学文案、保存提示和选项说明，必要补充改为 info 弹层；保留读屏说明、标签和错误提示。
- 原生 popover 增补 Escape 与焦点返回处理；不在窗口布局变化时立即关闭弹层，避免预览和尺寸调整时信息闪退。
- 问卷在 390px 下选择两列，避免 Windows 等标签与中文词组出现不自然断行。
- 手机上固定操作区要预留足够内容空间，并计算屏幕顶部、底部安全区域。
- 检查的是系统 Edge 的手机视口与触摸模拟，尚未进行实体 iPhone／安卓设备验收。
