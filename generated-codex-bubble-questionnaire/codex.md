# Codex 生成 · 开发记录

## 工作边界

- 仅在 `generated-codex-bubble-questionnaire/` 内创建和编辑文件。
- 不修改现有页面、问卷、数据、项目文档及配置。
- 不参考已有 HTML 的风格、元素、结构或布局；未读取这些文件。
- 阅读了 roadmap、README、v6 文字稿、问卷配置、页面清单与引擎接口。

- 中文排版参考 `.claude/skills/zh-web-typography/SKILL.md`；无 emoji，控件使用内联 SVG。

## 设计方向

依据用户后续明确要求，只保留雾蓝浅色主题。用克制的外凸、内凹和哑光表面建立触觉层级。圆形几何用于品牌、主视觉和选项本身；每个选项以“戳气泡”方式选择，选中后凹陷，点击的 220 毫秒内出现轻微压缩反馈。排序题选中项移到上方，以整个条目支持鼠标、触屏拖动，前方小气泡显示名次并能取消选择。布局与项目现有星空、纸面样式独立。

用户最新要求先看样张，本轮以三张可直接打开的浅色样张为交付边界，不继续扩展功能。`ranking-sample.html` 使用内存示例，不覆盖用户的答题存档。

## 已遇到的问题

- 初次 shell 调用长时间未返回，恢复后才开始读取和生成文件。
- Windows PowerShell 对 Node `-e` 内嵌引号的传递不稳定；较长逻辑写入本目录的 `.mjs` 后执行。
- 页面清单中的题数落后于当前 v6，遵循 `questions.json` 的题号与四部分配置。
- `q7` 是显示第 6 题，`q6` 是显示第 7 题；不得根据配置 id 推断展示顺序。
- 页面以传统脚本加载独立数据快照，避免 `file://` 下 fetch／ES module 的跨源限制。

## 验证

系统 Edge 对当前手机样张执行了 65 项检查，全部通过，未出现未捕获的脚本异常：

- 单一浅色主题，选项单列纵向排列，气泡在文字左侧，选中后凹陷，再戳可取消多选。
- 排序选项被选中后离开下方气泡区，进入上方已选列表。
- 鼠标拖动整个条目可以改变顺序，触屏拖动同样有效。
- 条目菜单中的上下移动仍可用，键盘方向键同样可以排序，取消选择后项目返回气泡区。
- 排序样张不会覆盖已保存的答卷，刷新恢复初始示例。
- 1440px 桌面上按手机宽度展示，320px、375px、390px、430px 手机视口无横向溢出，减少动态效果偏好生效。
- 首页主操作在手机一屏内，答题主操作固定在底部。
- info 弹层能按需展开、在视口内展示、通过 Escape 关闭；选项 info 不会误触选择。
- 用浏览器可访问性树确认原生复选框保留准确的名称。

## 后续经验

- 排序气泡被移入上方列表后，要把键盘焦点交给新条目，不能继续定位已经从下方移除的控件。
- 对整行使用 Pointer Events，可以共享鼠标、触屏交互。只在排序行限制触摸滚动，页面其余区域仍能正常上下滚动。
- 在拖动开始时批量读取位置，移动时只改 transform，结束后再更新数据顺序；取消手势时恢复原顺序。
- 原生 dialog 的 close 事件是异步的，自动检查应等待滚动锁释放，不能用固定的极短延时判断。
- 根据用户最新要求及时收敛到样张，正式上线与全面流程验收留待设计确认之后。

## 标题与项目排版规范

- 已读取 `.claude/skills/zh-web-typography/SKILL.md`。字体采用其中的系统黑体栈，标题 32px／48px，正文 16px／24px，手机页边距 16px，主要间距以 6、12、24、36、48、72px 变量定义。
- 之前按要求采用两端对齐；用户随后要求两行字距统一，因此改回自然左对齐、`letter-spacing: 0` 和正常词间距，覆盖前一轮的两端对齐要求。
- 中文标题使用均衡换行，减少尾行过短和“什么”等词被拆开的问题。
- 删除题目 info 中自动添加的通用操作开场白，原题目说明不截断。没有补充信息时不展示空 info；读屏操作说明仍保留。
- 浏览器检查包含标题对齐、字号行距、页边距、选项纵向位置与气泡左置，以及有／无题目补充说明两种情况。

## 小气泡与视觉对齐

- 普通选项气泡从 64px 缩为 44px，与排序气泡采用同一个尺寸变量；图标和勾选标记同步缩小，整行标签仍可点击。
- 普通选项与排序项使用统一的 12px 内边距、16px 列间距、44px 气泡列。二者气泡中心线、文字左边线一致，填空也对齐文字列。
- 标题、进度条、底部操作使用同一页面边界；页头操作、题目 info、选项 info 与底部箭头统一右侧列位。
- 标题每行字距不同的原因是 `text-align: justify` 会拉宽非末行，而末行保持自然字距；只设置 `letter-spacing: 0` 无法阻止对齐算法补入的间距。要求统一自然字距时应取消两端拉伸。
- 浏览器验证增加小气泡尺寸、两类气泡中心线、两类文字左边线检查，拖拽与辅助操作仍通过。

## 第一题气泡简化

- 按用户要求删除第一题气泡中央的设备图标和“其它”的加号；保留选中状态的角标、按压反馈与原生表单标签。
- 这是展示内容的小改动，仅检查脚本语法与差异，未重跑整套浏览器检查。

## 底部按钮对齐

- 返回按钮与下一题按钮采用同一个 56px 高度变量，保持上下边缘一致。
- 下一题按钮的文字与箭头一起靠右，间距 12px；相同底部组件也应用于排序样张。
- 底部主按钮悬停时不再上移，避免两个按钮在鼠标预览时错位。

## 首页逐颗戳泡泡

- 16 颗泡泡改为独立原生按钮，通过 `aria-pressed` 表达凸起／凹陷状态，再戳可恢复；保留初始主视觉中的少量凹陷圆点。
- 使用与答题页一致的短促按压动画，减少动态效果设置下停用动画；连续点击会取消前一段动画，避免状态与动画错开。
- 主视觉外部尺寸保持一致，调整内部留白，让每颗泡泡触摸目标至少 44px。
- 原生按钮处理空格与回车，不重复模拟点击；方向键、Home、End 在组内移动，采用单个 Tab 停靠点，操作说明仅供读屏读取。
- 浏览器验证新增独立状态、再次恢复、相邻泡泡不受影响、真实触摸事件、方向键、原生 Enter 与减少动态效果等检查。Windows 的 CDP Enter 测试需要发送完整的回车文本事件。

## 轻盈开源字体

- 用户确认思源黑体搭配 Inter。中文标题使用 Light 300，正文和按钮用 Regular 400，选中项也不再用 600；状态由凹陷、勾选和颜色表达。字号、行高、字距和对齐保持现有设置。
- 从 Adobe 与 Inter 官方仓库下载字体及 OFL 许可证。中文原始字体每份约 8.4 MB，按首页、全部问卷、项目资料和交互文案生成 WOFF2 子集，各约 196 KB；Inter 可变字体约 352 KB，总计约 744 KB。
- 中文修改后的字体重命名为 Memory Han Sans，并保留原始版权、许可证和来源记录；仅 CSS 家族别名为 Memory Inter 的 Inter 文件未经修改。所有资源本地加载，不依赖用户已安装字体或远程字体服务。
- 增加 `build-fonts.py` 和字体 manifest，原始大文件保存在忽略的 `.font-sources/`。新增页面或数据文字后应重新生成字体子集。
- `fontTools.ttLib.woff2.haveBrotli` 可用于检测实际 WOFF2 支持，环境没有 `brotli` 包也可能通过 `brotlicffi` 支持压缩，不应重复安装依赖。
- 浏览器检查等待 `document.fonts.ready`，再用 `CSS.getPlatformFontsForNode` 确认 Light、Regular 和 Inter 实际参与渲染；仅检查 CSS 的 font-family 声明不能证明没有回退。
- 原生 `file://` 打开已验证本地 WOFF2 正常加载。字体检查与原有手机、排序、气泡交互检查共 65 项通过。
